✨ What Can Go Wrong & Our Enhancements
  • The Stale Cache Bug: If you add or delete a product without invalidation, clients receive old data for 60s. We implemented automatic cache.del('products') on POST and DELETE.
  • Database Offline Fallback: If MongoDB is temporarily down, the app smoothly serves fallback catalog without crashing.
  • Live Telemetry: Added response time benchmarks and TTL remaining countdown.

Add New Product
