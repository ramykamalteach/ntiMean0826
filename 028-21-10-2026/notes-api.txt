Restful :  

    - multiple ways to fetch data from a RESTful service :
        1- HttpClient (recommended)
        2- Fetch API (Native JavaScript)
        3- RxJS ajax (from rxjs/ajax)
        4- GraphQL Clients (if API is GraphQL)
        5- Third-party Libraries (such as axios)

    ** Use HttpClient for RESTful APIs because:
        - It integrates with Angular's DI.
        - Works with interceptors (auth, logging).
        - Handles Observables (better than Promises for streams and cancelation).

Restful to get Meals from backend :

    - Create proxy.conf.json in root   (no change)
    - its code :
        {
            "/api": {
                "target": "http://localhost:3001",
                "secure": false,
                "changeOrigin": true
            }
        }

        > ng serve --proxy-config proxy.conf.json

    - add provideHttpClient() to providers in app.config.ts

        import { ApplicationConfig, provideBrowserGlobalErrorListeners } from '@angular/core';
        import { provideRouter } from '@angular/router';
        import { provideHttpClient } from '@angular/common/http';

        import { routes } from './app.routes';

        export const appConfig: ApplicationConfig = {
            providers: [
                provideBrowserGlobalErrorListeners(),
                provideRouter(routes),
                provideHttpClient()
            ]
        };

    - [CHANGED] Create a Service to Fetch Data
        > ng g s services/Product.service
        - code :

            import { HttpClient } from '@angular/common/http';
            import { Injectable, inject } from '@angular/core';
            import { Observable } from 'rxjs';
            import { Product } from '../interfaces/product';

            @Injectable({
                providedIn: 'root'
            })
            export class ProductService {
                private http = inject(HttpClient);
                private apiUrl = '/api/v1.0/products';

                getMeals(): Observable<Product[]> {
                    return this.http.get<Product[]>(this.apiUrl);
                }
            }

        

    - [CHANGED] Create Component and Use the Service in a Component
        > ng g c components/Products
        - code :

            import { Component, inject, OnInit, signal } from '@angular/core';
            import { Product } from '../../interfaces/product';
            import { ProductService } from '../../services/product.service';

            @Component({
                selector: 'app-products',
                imports: [],
                templateUrl: './products.html',
                styleUrl: './products.css'
            })
            export class Products implements OnInit {
                private productService = inject(ProductService);
                products = signal<Product[]>([]);

                ngOnInit(): void {
                    this.productService.getMeals().subscribe((data) => {
                        this.products.set(data);
                    });
                }
            }

        

        [OPTIONAL] shorter way with toSignal (no ngOnInit, no subscribe) :

            import { Component, inject } from '@angular/core';
            import { toSignal } from '@angular/core/rxjs-interop';

            export class Products {
                private productService = inject(ProductService);
                products = toSignal(this.productService.getMeals(), { initialValue: [] });
            }

            (the template is the same: products())
